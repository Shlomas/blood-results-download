Open-source notices

Blood Results includes open-source software. License files and notices are included with the installed application. Source materials for copyleft components distributed in the Windows package are available with the matching GitHub Release.

Major components

  • Electron, Chromium and Node.js, with notices included by Electron.
  • PDF.js 6.4.299, licensed under Apache-2.0.
  • node-poppler, licensed under MIT.
  • node-poppler-win32 2.0.0, licensed under GPL-3.0-or-later, containing Poppler 26.02.0 and supporting libraries.

Source materials

See the assets and notes attached to the v0.3.0 release. The upstream projects are node-poppler-win32, poppler-windows, Poppler, and conda-forge poppler-feedstock.

To request a copy of source materials if an attached archive is inaccessible, open an issue in the distribution repository.

No warranty

The bundled open-source components are provided under their respective licenses and without warranty. Refer to the complete license text shipped with each component.
